# Ảnh minh hoạ nội thất

Ảnh hiện ở trang chi tiết căn, mục "Nội thất chi tiết" (nhãn "Ảnh minh hoạ"). Mỗi hạng mục dùng chung 1 ảnh cho mọi căn.

- Tên file: `<code>.jpg` với `code` 1–32 theo `backend/src/modules/inspection/inspection.catalog.ts`. Ví dụ `1.jpg`, `24.jpg`.
- Tỉ lệ khuyến nghị 4:3 (vd 800x600), dung lượng <= 150KB mỗi ảnh.
- Thiếu file thì web tự ẩn ảnh của hạng mục đó (không hiện icon vỡ).
- URL công khai: `/inventory/<code>.jpg`.
